What you're downloading

  • Single file, no installer. Download tetris.exe and double-click — it opens straight into a console window.
  • Statically linked. No MSYS2, no MinGW, no extra runtime to install. Runs on any up-to-date Windows 10 or 11 machine.
  • Full mechanics. Seven-piece rotation, gravity that speeds up by level, line clearing, scoring, pause, and a play-again prompt on game over.
  • Polished terminal UI. A title screen with the current version number, aligned controls reference, and a board that stays centered even if you resize the window.
  • Open source. Written in plain C with CMake — read the source or build it yourself on the GitHub repo.
