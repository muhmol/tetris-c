# tetris-c

A terminal-based Tetris clone written in C, built with CMake.

## Build

\`\`\`
cmake -S . -B build
cmake --build build
\`\`\`

## Run

\`\`\`
./build/tetris
\`\`\`

## Controls

| Key   | Action      |
|-------|-------------|
| A     | Move left   |
| D     | Move right  |
| S     | Soft drop   |
| W     | Rotate      |
| Space | Hard drop   |
| Q     | Quit        |
